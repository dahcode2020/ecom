# Project memory

## Product intent & audience

- Projet Next.js en cours de développement dans l'environnement Bolt.
- L'utilisateur communique en français ; répondre en français à chaque tour.

## Brand personality & voice

- Ton direct, transparent, rassurant sans verbiage.
- L'utilisateur est sensible à la consommation de tokens : privilégier les vérifications ciblées et les réponses concrètes, éviter les explorations longues non justifiées.

## Visual design & UX direction

- Non encore inférée depuis le contexte disponible.

## Decisions, constraints & rationale

- Le code du site compile sans erreur ; le build passe.
- Un incident d'aperçu vide a été observé : la cause est environnementale (réinitialisation du bac à sable / disparition du dossier de build), pas une régression du code.
- Reconstruction du site effectuée avec succès.
- Recommandation donnée à l'utilisateur : envoyer un nouveau message pour relancer le serveur Bolt, ou ouvrir l'adresse d'aperçu dans un nouvel onglet.

## Open questions & assumptions

- On suppose que l'aperçu se reconnectera après un nouveau tour de conversation ; à confirmer.
- Aucune direction visuelle/design n'a encore été exprimée ou inférée.
